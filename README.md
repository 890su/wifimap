# Wi-Fi Планировщик

Веб-приложение (PWA) для планирования покрытия Wi-Fi дома и офиса. План этажа, масштаб, стены и точки доступа дают живую карту сигнала на 2.4 и 5 ГГц и оценку скорости для клиентов.

Интерфейс на русском, строки вынесены в словари `src/i18n` (есть английский).

## Локально

```bash
npm install
npm run dev
```

Приложение открывается на [http://127.0.0.1:43123](http://127.0.0.1:43123).

```bash
npm test          # модель распространения и пропускной способности
npm run test:e2e  # Playwright: десктоп и телефон
npm run build     # статика в dist/
npm run preview
```

Встроенный режим: `/?embed=1` прячет название продукта в шапке.

## Что умеет MVP

- План: изображение, PDF (первая страница, pdf.js), камера на телефоне или пустой лист.
- Масштаб по двум точкам с известной длиной.
- Стены: отрезок, комната, карандаш с выпрямлением, привязка к углам и сетке, отмена и повтор.
- 10 материалов с затуханием на 2.4 и 5 ГГц.
- Точки доступа: роутер провайдера, Wi-Fi 5, Wi-Fi 6, mesh, репитер. Подключение: кабель, репитер по радио, mesh по радио или по кабелю.
- Клиенты: телефон, ноутбук, телевизор, приставка, компьютер.
- Карта сигнала считается в Web Worker (многостенная модель) и рисуется через WebGL2, с запасным Canvas.
- Тариф провайдера и по каждому клиенту: приём, отдача, пинг, джиттер и оценки серфинга, видео, звонков, стриминга, игр и облачного гейминга.
- Простой и расширенный режим.
- Мышь на десктопе, на телефоне — жест двумя пальцами и нижняя панель.
- Проекты в IndexedDB, скачивание JSON и экспорт PNG.

Модель — чистые функции в `src/model` (потери в свободном пространстве, показатель затухания, сумма пересечённых стен, PHY/MAC, делёж тарифа и радиоаплинка).

## Деплой на Cloudflare Pages

Сборка статическая, учётные данные в репозиторий не входят. Из корня проекта:

```bash
npm install
npm run build
npx wrangler pages deploy dist --project-name wifiplan
```

`wrangler.toml` задаёт `pages_build_output_dir = "dist"`. Первый деплой создаст проект Pages с именем `wifiplan`, если его ещё нет (нужен вход: `npx wrangler login`).

В `dist` попадают `public/_headers` и `public/_redirects`. Заголовок `Content-Security-Policy: frame-ancestors *` разрешает вставку в iframe; `X-Frame-Options` не задаётся. `/* /index.html 200` отдаёт приложение для неизвестных путей. Файлы и Pages Functions имеют приоритет над этим правилом.

### Короткие ссылки

По умолчанию выключены: `SHORT_LINKS_ENABLED = "false"`. Функции лежат в `functions/` и на выключенном флаге отвечают `501`.

Чтобы включить:

```bash
npx wrangler kv namespace create LINKS
```

Впишите id в `wrangler.toml`, раскомментируйте `[[kv_namespaces]]` и поставьте `SHORT_LINKS_ENABLED = "true"`. Тогда `POST /api/short-links` сохраняет JSON проекта, а `GET /s/:code` ведёт на `/?link=code`.

## Ограничения

Модель двумерная и многостенная: без отражений, дифракции и диаграмм направленности. Карта показывает лучший RSSI, не SINR. Скорость — инженерная оценка (эффективность PHY, равный эфир на точке, тариф делится между всеми клиентами). Пока нет 6 ГГц, нескольких этажей, калибровки по замерам и правки отдельных вершин стены. PDF берётся с первой страницы. Короткие ссылки не работают, пока флаг и KV не включены.
